Kurulum Rehberi

1. n8n'de ucus_radari_webhook.json workflow'unu import edin.

2. Workflow içindeki iki webhook node'unu aktif edin (üç nokta → Activate).

3. Yukarıya n8n sunucu adresinizi girin ve kaydedin.

4. Bu HTML dosyasını web sunucunuza koyun (nginx, Apache, Cloudflare Pages, Vercel vb.).

5. CORS için n8n'de WEBHOOK_ALLOWED_ORIGINS=* veya sunucu domaininizi tanımlayın.

6. Günlük otomatik tarama için ucus_alarmi_tarama_v2.json workflow'unu ayrıca import edin.
